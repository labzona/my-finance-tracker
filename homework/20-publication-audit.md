# Перевірка перед публікацією на GitHub

25.10.2026. Об’єкт перевірки — цей локальний репозиторій, усі його refs, доступні історичні та невикористані Git-об’єкти, робочі файли й правила виключення. На GitHub нічого не публікувалося, налаштування PythonAnywhere не змінювалися.

## Результат аудиту

| Перевірка | Результат |

| Вміст документів | Перевірено текст PDF та вкладені XML/relationships Word/Excel, а також архів розгортання. Помилок читання чи підозрілих ключів/паролів не виявлено |

| Перевірка виключень | Окремо перевірено 43 типові приватні шляхи та 14 потрібних публічних файлів. Приватні шляхи ігноруються, код/приклади/документи зберігаються; конфліктів із уже відстежуваними файлами немає |
| README | Є вимоги Python/uv, встановлення через uv sync --frozen, налаштування власних паролів, локальний запуск та команда uv run --frozen python verify.py. Вхідні дані з продакшену не потрібні |
| Чисте клонування | Чистий локальний клон коміту edc7081 без runtime/, data/, .venv/, .env і згенерованих файлів: точна команда uv run --frozen python verify.py завершилася з кодом 0. 25 тестів — OK, bean-check без повідомлень, усі чотири контролі збігаються |

Пошук охоплює формати приватних ключів, API/GitHub/AWS/Supabase-токенів, JWT, парольних хешів, облікових даних у URL та явні присвоєння секретів. Значення можливих збігів не виводяться. Це локальна перевірка вмісту, а не зміна чи аудит віддаленого акаунта PythonAnywhere.

Окремо перевірено спрацювання на два навмисно неправильні рядки у негативних тестах входу/конфігурації. Вони не є робочими паролями; коректні тестові паролі та хеші створюються випадково під час запуску. Приклади не замінюють і не розкривають даних входу опублікованого трекера.

Виключення перевірено також для SQLite-файлів поза runtime/ й випадково скопійованих виписок. Початкові джерела та фінансові розрахунки не змінювалися. Файл .gitignore захищає звичайне додавання файлів; приватні файли навмисно не додаємо примусово.

## Опублікований трекер

Користувачка повідомила про успішні HTTPS, вхід Марка, місячний звіт на телефоні та збереження тестової 1 PLN після оновлення. Цей результат відокремлено від наших локальних перевірок; адресу й паролі в репозиторій не додавали. Строк доступності до 09.11.2026 має зберігатися відповідно до умов здачі.

## Рішення

**Підготовлений локальний репозиторій можна робити публічним за результатами цього аудиту.** Вилучення секретів чи переписування історії не потрібне. Після чистого клону встановлено тільки залежності чинного uv.lock із наявного кешу, без приватних файлів. Фінансові розрахунки й навчальні джерела залишилися незмінними; порівняння коду обліку з попереднім перевіреним комітом 5a2801d не показує змін.

Публікацію GitHub не виконано. Налаштування PythonAnywhere не змінено. Два локальні коміти цього кроку містять лише правила виключення, README, звіт і прогрес.
