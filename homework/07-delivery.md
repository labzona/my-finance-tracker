Оновлено 22.10.2026. Для завантаження: [Word](product-decision.docx). Також синхронізовано [PDF](product-decision.pdf) і [HTML-джерело](product-decision.html). Документ не завантажено на Eduworkspace; трекер ще не реалізований.

## Зміст п’яти сторінок

1. Контекст, обмеження, п’ять Must і три Should з годинами.
2. Could/Won’t, вкладені 19/20/22, фінансова логіка й накопичувальний час.
3. Value vs Effort для п’яти фіч, обмеження RICE та формули подушки.
4. Роадмап із сигналами, Supabase/mobile-first/деплой, чотири відповіді про AI.
5. Бюджет за місяцями 1–12, джерела, курс NBP й окупність.

Поточна декомпозиція — [аналіз коду](12-technical-estimate.md) з [оновленням Supabase/PWA](15-estimate-update.md). Старі генератори build_estimates.py/feature-estimates.json до фінального документа не застосовувати.

## Перевірки

- Word і PDF: по п’ять сторінок A4, сім таблиць, активні джерела, український текст.
- Усі десять сторінок двох рендерів переглянуто після остаточної правки: без обрізання, накладань, відсутніх символів чи зайвих сторінок; Word збігається з HTML за 278 текстовими блоками.
- Початкові 1–18 і додаткова 21 враховані один раз; групи 5 Must / 3 Should / 3 Could / 8 Won’t. 19/20/22 — складові 2/9.
- П’ять балів V/E, всі суми активних фіч, нові 98,5/131,33 год ядра та бюджет 60+60+30=150 звіряються з джерелами.
- Розрахунок NBP від 22.10: 3,8886 PLN/USD; річна база 54 396,18 PLN; поріг для $150 ≈1,07%.
- Відмова від магазинів описана один раз у розділі обмежень, разом із мобільним ярликом; одноразовий платіж не поданий як щорічний.
- Без нових пакетів. Стандартний DOCX-рендерер недоступний через pdf2image; для перевірки використовуємо Pages → тимчасовий PDF → PNG системним PDFKit. Це перевірка через Pages, не гарантія тотожної верстки кожної версії Word.
