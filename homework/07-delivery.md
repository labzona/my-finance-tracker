## Перевірки

- Word і PDF: по п’ять сторінок A4, сім таблиць, активні джерела, український текст.
- Усі десять сторінок двох рендерів переглянуто після правки від 25.10: без обрізання, накладань, відсутніх символів чи зайвих сторінок; текст Word звірено з HTML.
- Початкові 1–18 і додаткова 21 враховані один раз; групи 5 Must / 3 Should / 3 Could / 8 Won’t. 19/20/22 — складові 2/9.
- П’ять балів V/E, всі суми активних фіч, 98,5/131,33 год ядра та бюджет 60+60+30=150 звіряються з джерелами. Новий план: 151 + P1 6 = 157 год; 157 + 54 резерв + 5 вільно = 216; місячна робота 54/50,5/52,5 год.
- Розрахунок NBP від 22.10: 3,8886 PLN/USD; річна база 54 396,18 PLN; поріг для $150 ≈1,07%.
- Відмова від магазинів описана один раз у розділі обмежень, разом із мобільним ярликом; одноразовий платіж не поданий як щорічний.
- Без нових пакетів. У поточному оновленні стандартний render_docx.py успішно створив п’ять PNG і перевірочний PDF через наявний bundled Python. Фінальний PDF із HTML окремо відрендерено PDFKit. Верстка в конкретній версії Microsoft Word може відрізнятися.

Після зміни HTML виконати з кореня проєкту:

```sh
uv run --offline --no-sync python -B homework/build_docx.py
uv run --offline --no-sync env ELECTRON_RUN_AS_NODE=1 '/Applications/Cursor.app/Contents/MacOS/Cursor' homework/build_document.mjs
uv run --offline --no-sync /usr/bin/swift -module-cache-path /private/tmp/my-finance-homework-swift-cache homework/verify_pdf.swift homework/product-decision.pdf /private/tmp/my-finance-homework-pdf-pages
```

Окремо відрендерити Word скриптом render_docx.py з навички documents, використовуючи bundled Python через uv; переглянути кожну сторінку. Якщо є зайва сторінка, обрізання або перенесений заголовок — виправити й повторити. Готовність документа не підтверджує готовність імпорту Марка, доступу чи готівки; це наступні завдання 08–11.
