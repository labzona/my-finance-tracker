# 07. Фінальний документ

Стан: завершено. Створено фінальний PDF рівно на п’ять сторінок і редаговане HTML-джерело; кожну сторінку PDF переглянуто після рендерингу. На Eduworkspace документ ще не завантажено.

## Що зробити

- Зібрати відповіді в один документ і перевірити узгодженість рішень.
- Умістити в PDF до п’яти сторінок: MSCW з обґрунтуваннями; методи й числовий приклад; роадмап із сигналами; AI з розрахунком; бюджет і окупність із курсом та джерелами.
- Зберегти вихідний документ і фінальний PDF у `homework/`. Не включати виписки, паролі чи зайві фінансові подробиці.
- Переглянути кожну сторінку PDF: таблиці читаються, рядки не обрізані, посилання й числа правильні. Не встановлювати нових пакетів без дозволу.

## Перевірка готовності

- Усі 18 фіч враховано, Must не більше п’яти.
- Два альтернативні методи названо й пояснено; один застосовано до п’яти фіч із числами.
- Є три етапи, сигнали переходу та чотири відповіді про AI.
- Бюджет не перевищує $200, окупність відповідає його сумі, джерела й дати вказано.
- PDF має не більше п’яти сторінок і пройшов візуальний перегляд.

## Результат

- [Фінальний PDF для здачі](product-decision.pdf).

## Виконані перевірки

- PDF має **5 сторінок A4**, текст українською виділяється й копіюється. Кожну сторінку перетворено на PNG і переглянуто: немає накладань, обрізаних рядків, зламаних таблиць або відсутніх символів.
- У PDF рівно **18 фіч**: Must 5, Should 2, Could 4, Won’t 7. Номери не повторюються. Час і обґрунтування залишено для кожної фічі; пріоритет подушки перед лімітами збережено.
- Збережено обидва методи, формулу й п’ять рядків RICE, розбіжність із MSCW і пояснення вибору. Перевірено бали 0,800 / 0,300 / 0,250 / 0,063 / 0,031.
- Є три етапи й сигнали переходу; трактування першого року та обмеження часу прямо зазначені. AI відкладено; ціна сценарію $0,026/місяць і приватність описані, у вибраному бюджеті API $0.
- Основний річний план **$150 із резервом**, альтернативний домен .com за **$11,08** і джерела вказані. Курс **1 USD = 3,8889 PLN**, таблиця **205/A/NBP/2026 від 21.10.2026**, контрольні витрати обох людей й арифметика перенесені без змін. Поріг окупності **≈ 1,07%**, або **48,61 PLN/місяць на двох**.
- Посилання на Intercom, Atlassian, модель і приватність OpenAI, PythonAnywhere, ліцензію Fava, Apple, Google, Porkbun і NBP збережені як активні PDF-посилання. У документі немає абсолютних локальних шляхів, ключів, паролів або рядків банківських виписок.
- Пакетів не встановлено, облік і `data/` не змінювалися. Використано наявні Chrome, вбудований JavaScript-рушій Cursor і системні засоби macOS; стандартних PDF-бібліотек Python у проєкті немає.

## Повторна побудова на цьому комп’ютері

Команди з кореня проєкту; вони не встановлюють залежностей. Після зміни HTML обов’язково повторити побудову, перевірку й візуальний перегляд усіх сторінок.

```sh
uv run --offline --no-sync env ELECTRON_RUN_AS_NODE=1 '/Applications/Cursor.app/Contents/MacOS/Cursor' homework/build_document.mjs
uv run --offline --no-sync /usr/bin/swift -module-cache-path /private/tmp/my-finance-homework-swift-cache homework/verify_pdf.swift homework/product-decision.pdf /private/tmp/my-finance-homework-pdf-pages
```

Наступний етап домашки — завдання 08: імпорт Марка та перевірки обліку обох людей. Готовність PDF не означає готовності практичного трекера.

## Додатково надано Word

На прохання користувачки створено `product-decision.docx`. Текст і шість таблиць редагуються; є стиль Title, заголовки, чотири явні розриви сторінок і автоматична нумерація. Збережено зміст HTML та посилання на джерела.

Стандартний `render_docx.py` не запустився через відсутній `pdf2image`; нових пакетів не встановлювали. Автоматичний експорт Microsoft Word завершився помилкою AppleScript `-1708`. Тому DOCX відкрито у встановленому Pages і експортовано в тимчасовий PDF: отримано **5 сторінок A4**, кожну перетворено на PNG через `verify_pdf.swift` і переглянуто. Обрізання, накладань і відсутніх символів немає; активні посилання збережені. Це перевірка через Pages, а не через рушій Word. Проміжні файли залишено в системній тимчасовій папці.

Повторне створення Word-копії після змін HTML:

```sh
uv run --offline --no-sync python homework/build_docx.py
```

Після повторної побудови потрібно знову перевірити сторінки. Основний PDF для здачі не змінено.
