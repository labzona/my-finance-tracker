# Прогрес

## Зроблено
- Проведено розмову з Олею: п’ять питань. Wolt — доставка; кафе й доставка окремо; фіксовані — регулярні платежі, які теж можна скасувати.
- Узгоджено період від фактичного дня зарплати до дня перед наступною. Зарплата 12-го відкриває період 12-го.
- Оновлено `PRD.md`, `IMPLEMENTATION_PLAN.md` і розділ «Проєкт» у `AGENTS.md`: три питання, формули, межі проєкту та перевірки кроків.
- Підтверджено каркас `main.beancount`: усі рахунки відкриті, початкові 4 500 PLN задано, згенеровані операції підключено через `include`.
- Імпортер читає всі CSV з `data/` і категорії лише з `rules.csv`, повністю перезаписує `transactions.beancount`. Правила не змінювалися. Уточнено усунення повторів за повною датою завершення та вибір кінцевого залишку при перекритті виписок без сортування банківських рядків. Надходження без правила доходу потрапляє в `Income:Інше`.
- Імпортовано 142 операції. `uv run python import.py` і `uv run bean-check main.beancount` завершилися успішно; перевірка обліку — без жодного повідомлення.
- Balance-твердження звірені: 01.09.2026 — 8 596,30 PLN; 01.10.2026 — 12 305,39 PLN; 16.10.2026 — 17 127,34 PLN. Це календарна звірка банку; майбутні звіти залишаються за періодами між зарплатами.
- Перевірено ідентичність повторного імпорту, усунення дублікатів двох CSV, перекриття дат і пріоритет правил. Тестові файли створювалися лише в тимчасовій папці; `data/` не змінювалася. Приватні та службові файли виключено з git.
- За новим окремим проханням Олі додано чотири нативні `query` за календарними місяцями: категорії; дохід, витрати, відкладено, відсоток і дата останньої операції; фіксовані / змінні; детальний список без категорії з роком і місяцем. Запити виконано окремо через `uv run bean-query`; усі успішні. За нульового доходу відсоток порожній, а не помилковий нуль.
- `uv run bean-check main.beancount` після додавання запитів — без повідомлень. Жовтень має останню операцію 15.10.2026 і залишається неповним.
- Fava запущено у фоновій сесії на `http://127.0.0.1:5050`; доступність підтверджено HTTP 200. Візуальний перегляд у браузері в цьому кроці не виконувався.
- Створено `report.py`: завантажує облік, виконує саме збережені запити 1–3 через beanquery та генерує автономний `report.html` українською. Перед генерацією звіряє суми категорій і фіксованих / змінних із загальними витратами.
- У звіті три блоки з головною цифрою, простими графіками та висновками, перемикач календарних місяців і позначка «Неповний місяць · дані до 15.10.2026». Дані, стилі й скрипт вбудовані; зовнішніх залежностей та нових пакетів немає. Витрати без категорії позначені як причина попередньої розбивки фіксованих / змінних.
- `uv run python report.py` успішно створив звіт за три місяці. Програмно перевірено перемикання всіх місяців, суми, відсотки, сім категорій, підпис жовтня та відсутність мережевих залежностей. `open report.html` успішно відкрив файл у стандартному браузері. Керований браузер недоступний, тому візуальну перевірку не виконано. `report.html` виключено з git.

## Ще не готове
- Шість операцій залишаються без категорії: Rossmann (2), Play (2), Decathlon (2). Нові правила навмисно не додавали за поточним проханням Олі; Wolt уже віднесено до доставки.
- Чотири поточні запити й HTML-звіт свідомо рахують календарні місяці за останніми проханнями; звіт за періодами між зарплатами з PRD ще не реалізований.
- Фіксовані / змінні витрати рахуються за наявним тегом `#fixed`: Play поки серед змінних через відсутнє правило. Це зміниться після доповнення `rules.csv` та повторного імпорту.

## Далі
Каркас, імпорт зі звіркою, чотири календарні запити та автономний HTML-звіт готові. Далі — за окремою вказівкою Олі доповнити категорії, повторити імпорт і перевірку та оновити звіт командою `uv run python report.py`. Окремо залишається звіт за періодами між зарплатами з PRD.
