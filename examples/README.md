# Штучні контрольні виписки

Тільки два навчальні джерела з домашнього завдання WIT 5, заняття 7. Це точні копії без редагування рядків:

- ola-statement.csv — навчальна виписка Олі з початкового data/statement.csv, 142 операції.
- marko-statement.csv — навчальна виписка Марка, надана користувачкою з умови, 109 операцій.

SHA-256 вихідних файлів записано в manifest.json і перевіряється командою `uv run python verify.py`. Контрольні суми взято з умови, а не підібрано зміною даних. Не замінюйте ці файли особистими виписками. data/ залишається лише для читання та не потрапляє до git.
