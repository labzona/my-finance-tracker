# План розробки

Кожен крок закінчується перевіркою. Облік вважається готовим лише після `uv run bean-check main.beancount` без жодного повідомлення. Після завершеного кроку оновлюємо `PROGRESS.md` і робимо коміт українською. Не комітимо `data/`, `transactions.beancount`, `report.html`.

## Крок 0. Документи проєкту
**Зробити.** Зафіксувати домовленості: `PRD.md`, цей план, `PROGRESS.md`, розділ «Проєкт» в `AGENTS.md`.

**Перевірити.** У документах є три питання Олі, валюта PLN, початковий залишок 4 500 PLN на 31.07.2026, список фіксованих витрат і правило заощаджень. Немає `import.py`, `main.beancount`, `report.py`.

## Крок 1. Каркас обліку
**Зробити.** Створити `main.beancount`: опції Beancount 3, валюта PLN, `open` для всіх рахунків з `AGENTS.md`, проводка початкового залишку 4 500 PLN на 2026-07-31, рядок `include "transactions.beancount"`. Поки імпорту немає — порожній `transactions.beancount`, щоб файл відкривався.

**Перевірити.** `uv run bean-check main.beancount` мовчить. Запит балансу на 31.07.2026 показує 4 500 PLN на `Assets:Банк`.

## Крок 2. Правила категорій
**Зробити.** Дописати в `rules.csv` те, чого ще немає у виписці: Play → `Expenses:Звязок` (фіксована), Rossmann → `Expenses:Косметика-і-Побут`, Decathlon → `Expenses:Спорт`. Конкретніші шаблони лишаються вище загальних (`Bolt Food` перед `Bolt`).

**Перевірити.** У файлі є всі магазини й сервіси з виписки. Play позначено як фіксована. `Bolt Food` стоїть вище за `Bolt`.

## Крок 3. Імпорт виписки
**Зробити.** Написати `import.py`: читає всі CSV з `data/` (лише читання), застосовує `rules.csv`, пише `transactions.beancount`. Не сортувати рядки. Однакові рядки (дата завершення, опис, сума, залишок) — один раз. Фіксовані витрати — тег `#fixed`. Без правила: витрата → `Expenses:Без-Категорії`, надходження → `Income:Інше`.

**Перевірити.** `uv run python import.py`, потім `uv run bean-check main.beancount` без повідомлень. Немає операцій у `Expenses:Без-Категорії` і `Income:Інше`. Залишок на рахунку після останньої операції збігається з колонкою Balance у виписці (17 127,34 PLN на 15.10.2026).

## Крок 4. Три збережені запити
**Зробити.** У `main.beancount` додати нативні директиви `query` (не `custom "query"`): витрати за категоріями по місяцях; норма заощаджень (дохід − витрати) / дохід; фіксовані (`#fixed`) проти решти витрат.

**Перевірити.** `uv run bean-check main.beancount` мовчить. Запити відкриваються і дають окремі цифри для серпня, вересня і жовтня. Жовтень видно як неповний.

## Крок 5. Перегляд у Fava
**Зробити.** Запускати Fava на порті 5050: `uv run fava -p 5050 main.beancount`.

**Перевірити.** У браузері відкривається `http://127.0.0.1:5050`. Видно рахунки, операції з тегом `#fixed` і збережені запити.

## Крок 6. HTML-звіт для трьох питань
**Зробити.** `report.py` будує `report.html` з відповідями на три питання Олі по місяцях. Жовтень підписати як неповний. Файл звіту в git не потрапляє.

**Перевірити.** `uv run python report.py` створює `report.html`. На сторінці є категорії, частка відкладеного і розбивка фіксовані / змінні для серпня та вересня; жовтень є, але позначений як неповний.
